# 化学方程式配平与守恒核对工作台

基于 Vue 3 + TypeScript + Vite 的教学工具，帮助学生理解配平系数如何同时满足**元素守恒**与**电荷守恒**。全部解析与求解在浏览器本地完成，使用 BigInt 与精确有理数运算，不做浮点近似。

## 启动方式

```bash
npm install          # 首次（仓库已附带 node_modules 时可跳过）
npm run dev          # 开发服务器，默认 http://127.0.0.1:5173/
npm test             # 运行 Vitest 测试（解析器 / 求解器 / 组件）
npm run build        # 类型检查 + 生产构建（输出到 dist/）
npm run preview      # 预览生产构建
```

## 输入语法

每种物质单独占一行，左右两栏分别为反应物和生成物。

- **元素与下标**：元素符号首字母大写（`Fe`、`Cl`），下标为正整数，如 `H2O`、`C6H12O6`。
- **分组括号**：支持多层 `( )`（也兼容 `[ ]`、`{ }`），括号外下标乘整个分组：`Ca(OH)2`、`Ca3(Fe(CN)6)2`。
- **结晶水**：用 `·`（或 ASCII `.`）分隔，点号后整数只乘该一段：`CuSO4·5H2O` 计为 Cu×1、S×1、O×9、H×10。
- **电荷**：写在整个化学式末尾，形如 `Mg^2+`、`SO4^2-`、`H^+`、`Cl^-`。
- **电子**：固定写作 `e^-`，带 1 个单位负电荷、不含任何元素。

解析错误（未知元素、空分组、下标为 0、括号不匹配、电荷位置非法等）会直接标红出错的那一行，并给出字符位置。

## 核心操作

- 每栏可添加、删除、上移/下移物质行；顺序即方程式中的展示顺序。
- **键盘操作**：输入框内 `Enter` 跳到下一行（末行自动新增）；空行按 `Backspace` 删除；`Alt+B` 全局触发配平。
- 点击「配平」后：
  - 有唯一最简正整数解时，展示易读方程式（系数 gcd 为 1）与守恒核对表（逐元素 + 电荷，列出左右总数）。
  - **无解**（只有零解）、**必须出现零/负系数**、**解空间多于一维**三种情况会分别说明原因，不会任选一组解冒充唯一答案。
- 点击核对表中的元素名，可在全部物质中突出该元素的单份含量（系数 × 含量即表中总数），便于追查嵌套分组与结晶水计数。
- 输入一旦修改或出现解析错误，旧结果立即显示失效横幅，不能继续复制为当前答案；重新配平后恢复。
- 「复制纯文本方程式」把结果复制为形如 `2H2 + O2 → 2H2O` 的纯文本。

页面内置四组示例：普通燃烧反应、多层嵌套分组、结晶水脱水、含电子的离子半反应（高锰酸根还原）。

## 限量试剂与投料方案

配平成功（唯一全正系数）后，页面下方出现「限量试剂与投料方案比较」区块；含电子 `e^-` 的半反应会提示不适用。

- **投料录入**：每种反应物填写非负数量，单位可选 `mol` / `mmol` / `g`；每种物质可填正摩尔质量（g/mol）。以 g 投料时必须填摩尔质量；未填摩尔质量的生成物只显示物质的量。空值、负数、非法文本会在对应字段标红定位，不会被当作 0。
- **计算假设**：反应完全进行、无副反应。把投料统一换算为 mol 后，以「各反应物物质的量 ÷ 配平系数」的最小值作为反应进度 ξ；并列限量试剂按精确相等判定。结果表列出换算依据、比例、各反应物消耗与剩余、各生成物理论产量（mol 与 g）。
- **精确性**：内部全程使用 BigInt 精确有理数比较与运算，不会因近似制造并列或负剩余；显示数值四舍五入保留 6 位小数，近似值以「≈」标注。
- **多方案比较**：可新建、命名、复制、切换、删除投料方案；复制后各方案独立编辑互不影响。所有有效方案并排对比限量试剂、反应进度与各生成物产量。编辑投料会使该方案结果失效；增删物质或修改化学式会使全部方案结果失效，需重新配平并补齐输入；物质调序时投料随对应物质移动。
- **投料示例**：区块内提供「试剂过量」（第一种反应物加倍）与「恰好配比」（按系数投料）两个一键填充示例。

## 求解原理

1. 解析器将每个物质展开为「元素 → 原子数」的整数计数与净电荷。
2. 以物质为列、元素与电荷为行建立齐次线性方程组（反应物取正、生成物取负）。
3. 用 BigInt 分子/分母的分数做高斯-若尔当消元，求零空间基：
   - 零空间为 0 维 → 无解；多于 1 维 → 解不唯一；
   - 1 维时把基向量通分取整、约去最大公约数，再检查是否全部为正。

## 目录结构

- `src/lib/elements.ts`：118 个元素符号表
- `src/lib/parser.ts`：化学式解析器（括号 / 结晶水 / 电荷）
- `src/lib/fraction.ts`：精确有理数
- `src/lib/solver.ts`：守恒矩阵与零空间求解
- `src/lib/stoichiometry.ts`：投料换算、限量试剂与理论产量计算
- `src/App.vue`：两栏录入、结果展示、守恒核对、投料方案与对比
- `src/lib/__tests__/`：解析器、求解器与组件测试
